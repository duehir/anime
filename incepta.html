Возможности парсера

Быстрый синтаксис

Интуитивные команды для создания графических примитивов, настройки экрана и циклов без лишнего бойлерплейта.

Аргументы CLI

Удобный запуск через терминал с поддержкой путей ввода файлов и флагов автоматического запуска результирующего скрипта.

Двойной вывод

Парсер автоматически сохраняет готовый код как в исполняемый `.py` файл, так и в удобный `.txt` формат для отладки.
